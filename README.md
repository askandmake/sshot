# 스샷

찍고, 표시하고, 가리고, 붙여넣는 윈도우 화면 캡처 프로그램입니다.
설치 없이 파일 하나로 켭니다. 무료입니다.

## 받기

**[최신 버전 받기](https://github.com/askandmake/sshot/releases/latest)** → `sshot-v1.0.0.zip`

- 압축을 풀고 `스샷.exe`를 두 번 누르면 켜집니다. (`읽어주세요.txt`와 오픈소스 라이선스가 함께 들어 있습니다)
- 윈도우 전용, 약 20MB
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (서명이 없는 개인 프로그램이라 그렇습니다)

## 하는 일

| 하는 일 | 단축키 |
|---|---|
| 부분 캡처 (끌어서 고른 곳만) | Alt+1 |
| 빨간 네모 그리기 | Alt+2 |
| 화면 번역 (고른 곳을 그 자리에서 한글로) | Alt+3 |
| 가리기 (검은 네모) | Alt+4 |
| 번호 도장 · 화살표 | Alt+5 |
| 같은 자리 다시 찍기 | Alt+6 |

찍은 그림은 파일로 남지 않고 클립보드로 갑니다. 바로 Ctrl+V 하면 됩니다.

## 알아 두세요

- 인터넷을 쓰는 때는 두 가지입니다.
  - 화면 번역을 쓸 때: 고른 곳에서 읽은 글자가 번역 서버(구글 번역)로 갑니다.
  - 프로그램을 켤 때: 새 버전이 있는지 한 번 확인합니다. 화면이나 PC 정보는 보내지 않습니다.
- 새 버전이 나오면 옛 버전은 쓸 수 없게 될 수 있습니다. 그때는 안내 창이 뜹니다.
- 쓰는 법과 안 되는 것은 압축 파일 안의 `읽어주세요.txt`에 있습니다.
